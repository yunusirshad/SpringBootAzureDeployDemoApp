How to read a row

Indicators are readings, not filters. RSI under 70 is not stretched. MACD up means the line is above its signal. ADX over 25 is a strong trend, and rising means the positive direction is above the negative. Band is where the close sits between the Bollinger bands.

API guide

GEX levels

Next listed expiry. The percent is that strike's share of open interest on the expiry, which is the pull toward the level. It is not a forecast.

Super core stock 0

The one name to buy. It has to be compliant, above the 1-hour 20 EMA, at least 1× relative volume, outside 3 days of earnings, and a quality pass. The closest to the breakout wins.

Top 10 stocks 0

The 10 strongest uptrends. A name qualifies only when the 50-day average is above the 200-day. Rank is that gap as a percent of the 200-day.

Core stocks 0

Every other name that qualifies. A name with the 50-day at or below the 200-day is left off both lists until it qualifies.
